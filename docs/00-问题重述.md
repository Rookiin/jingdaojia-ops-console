# 净到家保洁 · 问题重述（一页）

> 本文件将客户原话翻译成可交付的问题陈述，作为后续诊断与方案的总纲。

## 客户原话
> "我这 8 个片区，7 个赚钱 1 个亏，我不知道那个亏的到底亏在哪。给我一套能看住每一单、每一笔赔付、每个阿姨、每个客户的东西。预算 45 万，先做 2 个片区，8 周给我看。"

## 拆成四个可交付方向 + 一个核心疑问

| 客户方向 | 翻译成"要看住什么" | 对应系统模块 |
| --- | --- | --- |
| 看住每一单 | 每单能回溯到：哪个片区 / 哪个阿姨 / 哪个客户 / 什么类型 / 金额 / 签到与完成时间 / 服务过程证据 | 工单追溯 |
| 看住每一笔赔付 | 每笔赔付能关联到具体工单、原因分类、定责（阿姨/客户/产品/无责）、金额与证据 | 赔付管理 |
| 看住每个阿姨 | 工时、提成、质量系数可量化、可复核，不再靠手算与印象 | 阿姨工时与提成 |
| 看住每个客户 | 历史单、投诉、赔付、复购/流失可查 | 客户档案 |
| **亏在哪** | 分片区把收入与各项损耗拆开算净利，定位亏损来源 | 片区损益看板 |

## 核心疑问（本项目的"真问题"）
客户真正要的不是"8 个表"，而是**能回答"西乡塘片区为什么连亏 14 个月、到底亏在哪"**的分片区账。
系统必须让"每单/每赔付/每阿姨/每客户"的数据**自动汇入片区的营收与成本**，才能把亏损拆到可执行的粒度（赔付 / 免费返工 / 空跑改约 ...）。

## 本期范围（一句话）
先做 **青秀（盈）与西乡塘（亏）两个片区** 作对照，8 周内上线一套可运行台账 + 看板，交付一个能解释"亏在哪"的试点，并证明可复制到下 6 个片区。
