## 6. 明确未验证 / 边界

1. **浏览器交互未自动化**：不引入 jsdom/Testing Library，点击、表单、滚动等交互仅由人工按 `README` 演示脚本走查；SSR 冒烟只证明「可渲染」。
2. **数据全部虚构**：由 `src/data/generate.js` 以固定种子 `20261031` 生成；不含任何真实客户、阿姨、手机号或地址。
3. **无外部服务**：无短信、支付、地图、对象存储调用；照片/签字均为 `mock://` 字符串。
4. **单机单浏览器**：持久化用 localStorage，多端并发、跨设备同步不在本期范围。
5. **权限为演示态**：approveCompensation 以入参 `role` 模拟审批层级，非真实登录鉴权。
