# 净到家保洁 · 片区经营看板（AI Native 交付试点）

一人软件公司为净到家保洁交付的第一个试点项目：一套"看住每一单、每一笔赔付、每个阿姨、每个客户"并可回答**"片区到底亏在哪"**的台账 + 经营看板。

## 技术栈
- Vite + React（前端单页应用）
- 本地 JSON 种子数据 + store 层模拟持久化
- 业务规则（提成、损益、赔付定责）抽为纯函数，便于单元测试

## 快速开始
```bash
npm install
npm run dev      # 本地开发
npm run build    # 生产构建
npm run test     # 运行单元测试
```

## 目录
- `docs/` — 诊断、方案、架构、商业方案、过程记录
- `src/` — 应用源码（模块与数据）
- `dev-team/` — Agent 库（团队定义）与知识库

## 数据边界
所有数据均为教学虚构；通知/短信等外部服务以桩实现；未使用任何真实客户数据、账号或凭据。
